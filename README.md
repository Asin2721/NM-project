# ComicCraft - AI Comic Story Creator

ComicCraft is a client-side AI comic generator application that turns story prompts into 5-panel comic strips complete with artwork, captions, and dialogues.

## Features
- **5-Panel Comic Arc**: Generates introduction, discovery, rising conflict, climax, and resolution panels.
- **Gemini AI Integration**: Uses Google Gemini API (or built-in fallback generative arc) for storyline creation.
- **AI Art rendering**: Integrates Pollinations AI & Canvas graphic engine for panel illustration.
- **PDF Export**: Compiles full print-ready 6-page PDF comic books directly inside the browser using jsPDF.
- **Source Code Export**: Downloadable project source code (.zip).

## How to Run
1. Double click `index.html` to open directly in any web browser.
2. No backend server or build process required!
3. Ready for instant deployment to Netlify, Vercel, or GitHub Pages.
